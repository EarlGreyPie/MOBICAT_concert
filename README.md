# MOBICAT 연주회 묶음

마비노기 모바일 연주회 도우미 [MOBICAT](https://github.com/EarlGreyPie/MOBICAT_Releases) 의 **관객용 연주회 묶음**을 두는 곳입니다.
연주회 공지의 링크를 누르면 MOBICAT 이 이곳에서 그날의 셋리 · 배치도를 받아 옵니다.

## 관객이라면

1. [MOBICAT](https://github.com/EarlGreyPie/MOBICAT_Releases/releases/latest) 0.9.3 이상을 설치하고 한 번 켭니다.
2. 연주회 공지의 링크를 누르고, 브라우저가 MOBICAT 을 열지 물으면 `열기` 를 고릅니다.
3. 앱이 연주회 묶음을 받을지 한 번 더 물으면 `예`. 공연 날마다 그날 판을 알아서 받습니다.

받기를 그만두려면 MOBICAT `설정 → 연주회 → 연주회 묶음 받기` 를 끄거나 비웁니다.

## 안전

- 묶음은 회차 암호로 잠겨 있습니다. 암호는 링크의 `#` 뒤에만 있어 이 사이트나 GitHub 로 보내지지 않습니다.
- 겉으로 보이는 것은 제목 · 날짜 · 시작 시각 · 기한뿐입니다.
- 안의 묶음에는 주최자 서명이 있고, MOBICAT 은 그 회차에서 처음 받은 주최자와 같은 서명만 적용합니다.
- 기한(마지막 공연 다음 날)이 지난 묶음은 앱이 쓰지 않고, 매주 월요일에 이곳에서도 지워집니다.

## 주최자라면

이곳에 묶음을 올리는 방법은 MOBICAT 제작자에게 문의해 주세요.
